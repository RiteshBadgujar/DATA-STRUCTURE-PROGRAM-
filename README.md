# 📚 Data Structure Program

A collection of basic **Data Structure and Algorithm programs written in C++**. This repository contains implementations of common sorting, searching, stack, and queue operations for learning and practice.

## ✨ Programs Included

- Bubble Sort
- Bubble Sort with User Input
- Insertion Sort
- Selection Sort
- Selection Sort with User Input
- Linear Search
- Stack Push Operation
- Stack Pop Operation
- Stack Peek Operation
- Queue Operation

## 🛠 Technologies Used

- C++
- Data Structures
- Algorithms
